# Anas Gara — DevOps portfolio

A responsive, buildless portfolio with locally hosted fonts and technology icons, original SVG infrastructure illustrations, project filtering, accessible project dialogs, and English/French CV downloads.

Run `npm run dev` and open http://127.0.0.1:4173. Run `npm run check` for a JavaScript syntax check. The complete deployable site is in `dist/` and can also be hosted on any static hosting service.

Project content is in `dist/app.js`; profile, experience, and contact content are in `dist/index.html`; design and responsive layouts are in `dist/styles.css`. No runtime dependencies, API keys, tracking, or external fonts are required.

Fonts: Manrope (Open Font License), Instrument Serif (Open Font License), IBM Plex Mono (Open Font License), obtained through Google Fonts. Technology icons: Devicon (MIT). Original CV sources are included in `dist/assets/` alongside the formatted PDFs. Portfolio contact uses the email published on the GitHub profile; supplied CVs retain their respective contact details.
